# 🪄 YouTube Downloader v2

> [!WARNING]
> این ابزار فقط برای استفاده محلی روی سیستم خودتونه. ویدیوها رو به ریپازیتوری کامیت نکنید و از GitHub Actions برای دانلود انبوه استفاده نکنید.

## درباره پروژه

یه ابزار ساده و رایگان برای دانلود ویدیوهای یوتیوب. قبلاً پولی بود، الان کاملاً رایگانه.

## امکانات

- دانلود با کیفیت‌های مختلف
- دانلود چند ویدیو همزمان
- زیرنویس فارسی و انگلیسی
- رمزگذاری و فشرده‌سازی
- دانلود فقط صدا

## نصب

1. پروژه رو Fork کنید
2. تب Actions رو فعال کنید

## استفاده

1. برید تب Actions
2. روی `YouTube Downloader` کلیک کنید
3. `Run workflow` رو بزنید
4. URL و کیفیت رو وارد کنید
5. فایل دانلود شده رو از Artifacts بگیرید

## مجوز

کاملاً رایگان و متن‌باز

## هشدار

فقط برای استفاده شخصی. از دانلود محتوای کپی‌رایت‌دار خودداری کنید.
